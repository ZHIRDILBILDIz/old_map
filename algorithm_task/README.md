## Как скачать, собрать и запустить

Требуется CMake (3.20+) и компилятор с поддержкой C++20.

```bash
git clone <ссылка_на_ваш_репозиторий>
cd <папка_проекта>

cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

./build/solver --daily-fee 10 --start 1
```

Параметры запуска (необязательные):
* `--daily-fee <число>` — дневная плата горнякам за расчистку одного обвала (по умолчанию `10.0`).
* `--start <вершина>` — номер стартового зала в 1-индексации (по умолчанию `1`).

## Формат ввода и интерактивного взаимодействия

Сначала в `stdin` подается описание графа:
```text
n m
cost_1, cost_2, ..., cost_n
u_1 v_1 p_1
...
u_m v_m p_m
```
* `n`, `m` — количество залов и ходов.
* `cost_i` — ценность залов (можно вводить как через запятую, так и через пробел).
* `u_i v_i p_i` — концы хода (1-индексация) и вероятность `p_i` (от `0.0` до `1.0`), что ход не обвалился.

Далее программа общается с пользователем (или тестирующей системой) командами:
* При выводе `LOOK` программа ждет через пробел статусы всех ребер, выходящих из текущей вершины (в том порядке, в котором они шли во входных данных): `1` — проход цел, `0` — завален.
* При выводе `MOVE <id>` программа ждет `1` (успешный переход) или `0` (неудачно).
* При выводе `CLEAR <id>` программа расчищает ход `<id>`, заканчивает день и на следующее утро начинает со стартовой вершины (ответа в консоль команда `CLEAR` не требует).
* При выводе `END` экспедиция завершается.
